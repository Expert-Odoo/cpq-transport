Features

Real road distance

Distance computed via Google Routes API — not straight-line estimates. Handles one-way and round-trip.

Places autocomplete

Origin and destination fields suggest real addresses after 3 characters. No more typos, no more failed lookups.

Zero-click computation

Once both addresses are validated, distance and line price update automatically. No extra button to click.

Unlimited services

Local delivery, long-distance, refrigerated, express — each with its own price per km and default origin.

Native Sales integration

Smart button on the quotation opens the configurator. Trip summary written back into the order line.

Full quotation history

Every configuration saved: addresses, distance, trip type, rate, computed price. Always auditable.

How it works

1

Create your transport services

Define each service with its Odoo product, default price per kilometer and default origin address.

2

Add transport to a quotation

Pick a transport product on any order line. A "Transport" smart button appears in the header.

3

Enter the destination address

Origin is pre-filled. Type the destination — Google Places suggests, you pick, distance is computed.

4

Quote updates automatically

Unit price, distance and trip summary written back into the sales order line.

Settings

One-time setup: paste your Google Cloud API key in Settings → Sales → Transport (CPQ).

Google Cloud setup

Create a project in Google Cloud Console, enable the two APIs below, generate an API key and paste it in Odoo Settings.

Required APIs

  • ›Routes API — distance and travel time (Compute Route Matrix endpoint).
  • ›Places API (New) — address autocomplete (Autocomplete endpoint).
  • ›Both share the same API key. Google Cloud offers a generous free tier.

Recommended restrictions

  • ›Application: server IP allow-list.
  • ›API restrictions: limit to Routes API + Places API (New).
  • ›Quotas: set daily limits to keep cost under control.
